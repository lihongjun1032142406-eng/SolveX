## 1. 软件概述与快速起步

欢迎使用 **SolveX** 是一款基于 Android 平台的 AI 屏幕解析工具。

SolveX 通过悬浮球交互，让您在任何 App 界面都能一键触发 AI 分析。无论是解数学题、翻译外文还是总结文章，只需轻轻一点。

## 2. 它能做什么？

- **解题答疑**：遇到不会的题目，截图发给 AI 获取详细解题步骤
- **翻译外文**：屏幕上的外语内容，一键翻译成中文
- **总结文章**：长篇文章快速提取核心要点
- **知识查询**：配合联网搜索，获取最新信息

## 3. 核心流程

整个使用过程只有三步：

1. **添加 AI 模型**
    - 打开 SolveX → 进入「设置 → 模型提供商」
    - 点击右下角 **+** 号，填写 API 地址和密钥
    - 支持 DeepSeek、OpenAI 等

2. **启动服务**
    - 返回首页，点击「启用解析」按钮
    - 按引导提示完成权限授予（悬浮窗、通知等）

3. **开始解析**
    - 打开任意 App，找到屏幕边缘的悬浮球
    - **单击**悬浮球即可触发 AI 分析
    - 解析结果会从侧边滑出，逐字显示

## 4. 环境准备

为了获得最佳体验，建议完成以下配置：

- **AI 接口配置**：进入「设置 → 模型提供商」，添加一个 API 密钥
- **无障碍服务**：如需使用「无障碍取字」模式，请在权限设置中开启 SolveX 无障碍服务
- **电池优化**：建议将 SolveX 加入系统电池优化白名单，防止后台被清理

> **提示**：首次使用建议先完成权限引导中的所有步骤，确保所有功能正常运行。
