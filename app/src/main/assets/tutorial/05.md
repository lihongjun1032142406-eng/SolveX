## 1. 进阶设置与隐私保护

除了基础的截图和分析功能，SolveX 还提供了丰富的进阶设置和隐私保护功能。

## 2. 智能助手

在「设置 → 智能助手」中，您可以创建多个 AI 角色，每个角色有自己独立的"性格"和"专长"。

**每个助手可以设置三类提示词：**

| 提示词类型       | 作用                    |
|:------------|:----------------------|
| **OCR 提示词** | 告诉 AI 如何从图片中识别和提取题目信息 |
| **文本提示词**   | 告诉 AI 如何分析纯文本内容       |
| **视觉提示词**   | 告诉 AI 如何分析包含图片的复杂问题   |

**使用示例：**

- **英语翻译助手**：提示词设为"请将以下内容翻译成流畅的中文"
- **代码审查助手**：提示词设为"请审查代码中的逻辑漏洞和安全问题"
- **数学解题助手**：提示词设为"请详细写出解题步骤，公式用 LaTeX 表示"

**切换助手：**

- 在首页配置看板点击「当前助手」
- 在弹出的底部抽屉中选择想要的助手
- 也可以进入「设置 → 智能助手」管理所有助手

## 3. 联网搜索

开启联网搜索后，AI 在回答时会自动查询互联网获取最新信息。

**适用场景：**

- 查询实时数据（天气、股价、新闻）
- 验证时效性信息（最新政策、事件）
- 补充背景知识

**配置方法：**

1. 进入「设置 → 联网配置」
2. 点击添加搜索引擎（支持 Tavily、Serper.dev、Brave Search）
3. 填写 API Key（需到搜索引擎官网申请）
4. 开启「联网搜索」总开关
5. 设置最大搜索结果数量（默认为 3 条）

**快捷开关：**

- 双击悬浮球打开扇形菜单
- 点击 **☁️ 图标**即可快速开启或关闭联网搜索

## 4. 悬浮球外观自定义

在「设置 → 悬浮球外观」中，您可以自定义悬浮球的显示效果：

- **悬浮球大小**：调整直径大小
- **旋转大小**：调整解析时的旋转动画大小
- **文字大小**：调整悬浮球上显示的文字大小
- **整体透明度**：调节整个悬浮球的透明度
- **内容透明度**：调节悬浮球内图标的透明度
- **启用菜单**：是否启用扇形快捷菜单
- **菜单项**：自定义菜单中显示哪些功能按钮

页面提供实时预览，调整后可以立即看到效果。

## 5. 防截屏保护

开启后（「设置 → 通用设置」→「防截屏保护」），SolveX 的悬浮球和结果窗口在系统截屏或录屏时，会自动显示为黑色方块，防止内容泄露。

这个保护覆盖三层窗口：

- 悬浮球
- 结果抽屉
- 选区裁剪遮罩

## 6. 隐匿模式（需要 Shizuku）

这是高级隐私保护功能，需要 Shizuku 授权才能使用。

**开启后的效果：**

1. SolveX 会从最近任务列表中隐藏，别人翻看后台时看不到
2. 系统会每 1.5 秒检测一次屏幕，当检测到有隐私保护的 App 在前台时，会自动加强自身保护
3. 从保护窗口切回普通窗口时，悬浮球会短暂隐藏 0.8 秒，避免被截图抓拍到

> 隐匿模式会增加设备耗电，如果遇到系统卡顿，请及时关闭此功能。

## 7. 隐藏悬浮球

在「设置 → 通用设置」中开启「隐藏悬浮球」后，悬浮球在无操作 5 秒后会自动收缩为屏幕边缘的一条窄线，减少遮挡面积。单击即可恢复完整大小。
