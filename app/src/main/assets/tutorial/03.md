## 1. 悬浮球手势与扇形菜单

悬浮球是 SolveX 的核心操作入口，学会使用它能大幅提升使用效率。

## 2. 手势操作一览

| 手势     | 空闲状态（未解析）        | 解析进行中           |
|:-------|:-----------------|:----------------|
| **单击** | 开始解析当前屏幕         | 展开或收起结果抽屉       |
| **双击** | 弹出扇形快捷菜单         | **立即取消**正在进行的解析 |
| **长按** | 切换引擎（文本 ↔ 视觉）    | 无效果             |
| **拖拽** | 移动位置，松手自动吸附到屏幕边缘 | 可移动位置           |

## 3. 手势详解

**单击（最常用）**

- 未解析时：触发一次完整的"截图 → AI 分析 → 显示结果"流程
- 解析进行中：展开或收回侧边的结果抽屉，方便查看内容

**双击**

- 未解析时：弹出一个扇形快捷菜单，提供常用功能入口
- 解析进行中：**立即强制取消**当前分析任务，用于点错或等待太久时自救

**长按**

- 在文本引擎和视觉引擎之间快速切换，无需进入设置页面
- 切换时会有震动反馈

**拖拽**

- 按住悬浮球拖动到屏幕任意位置
- 松手后自动吸附到最近的屏幕边缘
- 如果悬浮球挡住内容，拖到另一侧即可

## 4. 扇形快捷菜单

双击空闲状态的悬浮球，会弹出一个扇形菜单。菜单会自动避开屏幕边缘，确保所有按钮都在可触范围内。

菜单包含四个功能项：

| 菜单项          | 说明           |
|:-------------|:-------------|
| **引擎切换（⚙️）** | 切换文本引擎/视觉引擎  |
| **联网搜索（☁️）** | 一键开启或关闭联网搜索  |
| **跳转设置（⚡）**  | 点击快速进入设置页面   |
| **打开百度（🌐）** | 用系统浏览器打开百度搜索 |

> 菜单项可在「设置 → 悬浮球外观」→「启用菜单项」中自定义勾选，不需要的可以取消。

## 5. 结果抽屉

解析完成后，屏幕侧边会滑出结果抽屉：

**特点：**

- **流式输出**：AI 的回答逐字显示，不用等到全部生成完
- **Markdown 渲染**：支持标题、列表、代码块等格式
- **公式渲染**：数学公式（LaTeX）会正确显示，不会出现乱码
- **工具记录**：如果 AI 使用了联网搜索等工具，底部会显示调用记录，点击可查看详情
- **关闭方式**：点击抽屉外的半透明灰色区域即可关闭

**自动滚动**：抽屉默认跟随最新内容自动滚动，方便阅读长回答。

## 6. 悬浮球自动隐藏

悬浮球闲置 **5 秒** 后，会自动收缩为屏幕边缘的一条窄线，避免遮挡内容。单击窄条即可恢复完整大小。

如果不需要自动隐藏，可以在「设置 → 通用设置」中关闭「隐藏悬浮球」选项。
