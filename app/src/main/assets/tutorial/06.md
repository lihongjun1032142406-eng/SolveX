## 1. 常见问题解答

**Q: 悬浮球用着用着就消失了？**

A: 这是 Android 系统的后台清理机制导致的。请尝试以下两种方法：

1. **加入电池白名单**：进入系统设置 → 应用 → SolveX → 电池 → 选择「不受限制」
2. **任务加锁**：在最近任务列表中，找到 SolveX 的卡片，向下拉或点击锁定图标

**Q: API 报错"Invalid Key"或连接失败？**

A: 请按以下步骤排查：

1. 检查 API Key 是否填写正确（注意不要有多余的空格）
2. 确认 API 账户是否还有余额或额度
3. 在提供商列表点击连接状态图标（⚡）测试连通性
4. 如果使用自签名或私有证书，开启「信任所有证书」选项

**Q: 截图总是一片黑？**

A: 部分金融类 App（银行、支付软件）会禁止第三方截图。解决方法：

- 切换到「无障碍取字」模式（不需要截图，直接读取文字）
- 或者换到没有保护的 App 中使用

**Q: 如何更换 AI 模型？**

A: 提供两种方式：

1. **灵活分配**：进入「设置 → 模式设置」，可以为 OCR 识别、文本分析、视觉分析分别指定不同的模型
2. **全局默认**：进入「设置 → 模型提供商」，在顶部「全局首选提供方」中设置默认提供商

**Q: 如何让 AI 更准确地回答我的问题？**

A: 可以尝试以下方法：

1. **调整助手提示词**：在「设置 → 智能助手」中，为不同的任务类型设置专门的提示词
2. **开启联网搜索**：让 AI 获取最新信息
3. **使用更强的模型**：切换到 GPT-4o、Claude 等更强大的模型
4. **缩小识别范围**：开启裁剪模式，只框选需要分析的区域

**Q: 不想用扇形菜单，能关掉吗？**

A: 可以。进入「设置 → 悬浮球外观」，关闭「启用菜单」即可。也可以只关闭不需要的菜单项，保留常用的。

## 2. 数据管理

**配置备份**

进入「设置 → 数据管理」，可以进行以下操作：

- **全量备份**：一键导出所有配置为 JSON 文件。包含模型提供商（可选含 API
  Key）、智能助手、搜索引擎、系统与外观设置。导出文件可保存到手机或云端
- **分项导出**：选择性地导出特定配置，每个项目可以单独选择，API Key 也可以选择是否包含
- **导入配置**：选择之前备份的 JSON 文件，导入前会显示配置预览，同名配置会被覆盖，不可撤销

**历史记录**

所有 AI 解析记录都存储在本地（不传云端）：

- **查看**：首页底部「历史记录」入口
- **搜索**：在历史页面顶部搜索关键词
- **详情**：点击任意记录查看完整内容、工具调用记录
- **删除**：长按记录 → 确认删除

**重置配置**

在数据管理页面底部有「重置所有配置」功能，可以清空全部数据并恢复到出厂状态。

> **注意**：此操作会删除所有配置和数据，且**无法撤销**。建议先备份再重置。

## 3. 数据安全声明

SolveX 坚持数据本地化原则：

- **API 密钥**：仅存储在本地设备，不会上传到任何服务器
- **历史记录**：存储在本地 Room 数据库，不上传云端
- **AI 请求**：直接发送到您配置的 API 地址，不经第三方中转
- **联网搜索**：仅在开启联网搜索且 AI 认为需要时才会发起网络请求

> 除非您主动发起 AI 解析请求，否则软件不会向任何服务器上传数据。
